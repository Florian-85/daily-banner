# legacy/profile

The profile generator exported from the Homelab repository (cards, data collection, publication), kept for reference
and for its 69 tests (`npm run test:legacy`). It is **not** part of Daily Banner v0.1, is not used by the action, and
still carries personal defaults (owner and organisation names). Those pieces are meant to live in other repositories
(see issue #1). Consider deleting this folder before the repository becomes public.
